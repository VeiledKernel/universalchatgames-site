UNIVERSALCHATGAMES · v1.4

Changelog

What changed in each release.

1.4.0 Latest

  • Reward pools: each game can list several rewards. One is rolled per round by weight. Money rewards scale between min and max with question difficulty. Command rewards run once from console, with %player% or {player} replaced by the winner's name.
  • Announcements show the exact prize through %reward%, and the winner message is configurable as engine-settings.win-message.
  • Trivia lines can end in |easy, |medium or |hard, so harder questions pay more.
  • Quizmaster's reward-multiplier now applies to money rewards only. Command rewards are unchanged.
  • Invalid reward entries are skipped with a numbered warning in the log. A game with no valid rewards is left out of rotation, and /chatgames audit flags it.
  • Upgrading: config.yml is never rewritten, so existing servers keep their file, and the old reward-amount still pays its exact value. To show the prize in announcements, add %reward% to your announcement-format lines, or compare against the new default config.
  • The Quizmaster villager is never saved to the world, so a restart during a round cannot leave it behind.
  • A negative or non-finite legacy reward-amount now disables that game's rewards, so it is never picked; /chatgames audit flags the game.

1.3.0

  • Wandering Quizmaster event: chance-based Villager spawns near a random player asking multiplied-reward questions (opt-in, off by default).
  • Per-player Bedrock buffer: late Bedrock answers win inside a grace window after the global timeout.
  • /chatgames audit operator diagnostic plus native command suggestions on Paper.

1.2.0

  • Trivia question bank and Guess-the-Number modes with per-mode weights.
  • Admin force-start and skip, player mute toggle, world blacklist.
  • Optional SQLite win tracking with fastest-time records and break announcements.
  • Bedrock-aware timeout extension when a Bedrock player is online.
  • Optional "Too slow!" feedback for late correct answers, capped per round.
  • Real Floodgate detection for Bedrock players with safe fallback.

1.0.0

Public release. Native Paper and Folia support. Multithreaded chat engagement engine with no main-thread lag and no database.

Chat games

  • Math Flash: random arithmetic challenges (addition, subtraction, multiplication) in chat.
  • Word Unscramble: random entries from your word list, shuffled, first to unscramble wins.
  • Typing Speed: custom phrases with response tracking and optional Exact Match Mode (punctuation, spacing, casing).

Smart broadcasts

  • Condition-based announcements instead of fixed-interval spam.
  • TPS triggers dispatch optimization tips only when performance drops.
  • Player-count minimums gate games and broadcasts on empty servers.

Mobile balance

  • Typing-time buffer for Bedrock (GeyserMC) players so touchscreen users are not out-competed by PC typists.

Concurrency

  • Atomic single-winner lock: simultaneous correct answers across regions pay exactly one winner. Double payouts impossible by construction.
  • Vault integration with console-command fallback when no economy is installed.

Text and reload

  • Native Adventure MiniMessage gradients, no legacy codes required.
  • /chatgames reload applies config mid-game without locking the server.

Install: drop the jar in plugins/ — see the install steps.
