UNIVERSALCHATGAMES · v1.5

Changelog

What changed in each release.

1.5.0 Latest

New games

  • Unreverse: a backwards word appears in chat; type it forwards to win.
  • Fill-in: a word with blanks appears; type the whole word.
  • Random characters: a random string appears; retype it exactly.
  • Word library: Unscramble, Typing, Fill-in and Unreverse can draw on every block, item and mob name; exclude-words removes entries.
  • Trivia ships with 53 fact-checked questions.

Difficulty and points

  • Five tiers, Very Easy to Very Hard; harder questions pay more points (difficulty-points in config.yml).
  • The tier shows through %difficulty% in announcements and reward texts.
  • Trivia tags |very-easy through |very-hard set the tier; |medium counts as Basic, and untagged lines count as Basic too.

Stats and leaderboards

  • Wins go to a win log that resets on storage.log-reset (MONTHLY, WEEKLY, DAYS:30 or NEVER); fresh installs track wins, upgrades keep their setting.
  • /chatgames stats shows period and lifetime totals (chatgames.stats; chatgames.stats.others for other players).
  • /chatgames top opens leaderboard menus (chatgames.top); the layout lives in leaderboard.yml and refreshes every leaderboard.refresh-seconds.
  • Heads show player skins, cached quietly in the background; game-list.textures.<game> (plus overall) sets custom head icons from skin texture values.

Round feedback and sounds

  • WIN, LOSE, TIMEOUT and SKIPPED each have their own mode (TITLE, CHAT, BOTH or NONE); muted players hear nothing, but the winner always gets the win.
  • Each game and event can set its own sounds; config.yml sounds fill the gaps, and "none" silences an event.

PlaceholderAPI

  • Optional soft dependency: %chatgames_points%, %chatgames_wins%, %chatgames_rank% and %chatgames_best%, each also per game (for example points_trivia), plus %chatgames_top_1_name% and %chatgames_top_1_points%, overall and per game (for example top_trivia_1_name); placeholders.none ("-") covers blanks.

Configuration

  • config.yml keeps engine, Bedrock, storage, Quizmaster and broadcasts; each game has its own games/<name>.yml; every player-facing string lives in messages.yml.
  • Winner feedback can be a title, chat, both or nothing (winner.mode in messages.yml); new installs show a title.
  • %game% shows each game's display-name, set in its game file.
  • The Quizmaster announcement prefix is editable (announcements.quizmaster-prefix, with %host%).
  • Safer reloads: a file with a YAML error keeps the previous settings, says so in chat, and logs the file name with the line and column of the error; config-version is reserved for a future layout change.
  • Upgrading: nothing changes until you choose to. Existing servers keep their config.yml chat-games sections and get one console note at startup. To switch, see "Switching to split files" in the manual.

Fixes

  • Reloading no longer stops Paper rounds, stacks game loops or leaves stale timeouts behind.
  • A winner who disconnects mid-payout is still paid and recorded.
  • An unknown trivia |tag warns in the console and plays on instead of jamming the round.
  • Times show as 1.53s, not 1.53ss.
  • The winning answer is remembered for 3 seconds after a round ends: late correct answers in that window get "Too slow!" (at most 2 per round) and stay hidden when hide-correct-answer is on.
  • Multi-word Unscramble entries scramble word by word and keep their spaces.
  • Prize amounts print as whole numbers ("223", not "223.0").
  • Non-ops get a clear reply instead of silence on start, skip, reload and audit.
  • "New record!" skips muted players but still reaches a muted winner.
  • TPS alerts jump the broadcast queue instead of being crowded out by the interval reminder.
  • A third "Too slow!" can no longer slip through when answers land at the same instant.

Upgrading

  • On an upgraded config, other players now see a lose line when someone wins, and everyone gets a "Time's up!" title on timeout; 1.4 sent neither. Set lose.mode and timeout.mode to NONE in messages.yml to keep the 1.4 behaviour.
  • "New record!" is a per-player record across all games, timed at payout.
  • Difficulty is relative to each game's own list, so adding a much longer word lowers the tier, and the prize, of the others.
  • Storage stays off on upgraded servers unless you turn it on; stats and leaderboards need it.

1.4.0

  • Reward pools: each game can list several rewards. One is rolled per round by weight. Money rewards scale between min and max with question difficulty. Command rewards run once from console, with %player% or {player} replaced by the winner's name.
  • Announcements show the exact prize through %reward%, and the winner message is configurable as engine-settings.win-message.
  • Trivia lines can end in |easy, |medium or |hard, so harder questions pay more.
  • Quizmaster's reward-multiplier now applies to money rewards only. Command rewards are unchanged.
  • Invalid reward entries are skipped with a numbered warning in the log. A game with no valid rewards is left out of rotation, and /chatgames audit flags it.
  • Upgrading: config.yml is never rewritten, so existing servers keep their file, and the old reward-amount still pays its exact value. To show the prize in announcements, add %reward% to your announcement-format lines, or compare against the new default config.
  • The Quizmaster entity is never saved to disk, so a restart during a Quizmaster round cannot leave it behind.
  • A negative or non-finite reward-amount turns off that game's prize pool, and the game leaves rotation.

1.3.0

  • Wandering Quizmaster event: chance-based Villager spawns near a random player asking multiplied-reward questions (opt-in, off by default).
  • Per-player Bedrock buffer: late Bedrock answers win inside a grace window after the global timeout.
  • /chatgames audit operator diagnostic plus native command suggestions on Paper.

1.2.0

  • Trivia question bank and Guess-the-Number modes with per-mode weights.
  • Admin force-start and skip, player mute toggle, world blacklist.
  • Optional SQLite win tracking with fastest-time records and break announcements.
  • Bedrock-aware timeout extension when a Bedrock player is online.
  • Optional "Too slow!" feedback for late correct answers, capped per round.
  • Real Floodgate detection for Bedrock players with safe fallback.

1.0.0

Public release. Native Paper and Folia support. Multithreaded chat engagement engine with no main-thread lag and no database.

Chat games

  • Math Flash: random arithmetic challenges (addition, subtraction, multiplication) in chat.
  • Word Unscramble: random entries from your word list, shuffled, first to unscramble wins.
  • Typing Speed: custom phrases with response tracking and optional Exact Match Mode (punctuation, spacing, casing).

Smart broadcasts

  • Condition-based announcements instead of fixed-interval spam.
  • TPS triggers dispatch optimization tips only when performance drops.
  • Player-count minimums gate games and broadcasts on empty servers.

Mobile balance

  • Typing-time buffer for Bedrock (GeyserMC) players so touchscreen users are not out-competed by PC typists.

Concurrency

  • Atomic single-winner lock: simultaneous correct answers across regions pay exactly one winner. Double payouts impossible by construction.
  • Vault integration with console-command fallback when no economy is installed.

Text and reload

  • Native Adventure MiniMessage gradients, no legacy codes required.
  • /chatgames reload applies config mid-game without locking the server.

Install: drop the jar in plugins/ — see the install steps.
