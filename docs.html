UNIVERSALCHATGAMES · v1.5

Docs

Install, commands, permissions, and every config key. One page, no hunting.

Install

  1. Drop universal-chatgames.jar into plugins/.
  2. Start the server once to generate config.yml, messages.yml, leaderboard.yml and the games/ folder.
  3. Optional: install Vault plus an economy backend. Without Vault, set engine-settings.reward-fallback-command. Optional: install PlaceholderAPI for the %chatgames_*% placeholders.
  4. Restart. Console must show UniversalChatGames enabled (scheduler: Bukkit) on Paper or (scheduler: Folia) on Folia.

Upgrading from 1.4 or earlier? Nothing is generated and config.yml is never rewritten, so your server keeps running as before. The three new games (Unreverse, Fill-in and Random Characters) stay off until their files are in games/, and stats and leaderboards need storage.enabled turned on.

Commands

/chatgames reload

Atomic config reload, safe mid-round. Permission: chatgames.reload (default op).

/chatgames start [mode]

Force a round now; rejects when one is active. Modes: MATH, UNSCRAMBLE, TYPING, TRIVIA, GUESS, UNREVERSE, FILL_IN, RANDOM_CHARS. Permission: chatgames.admin (default op).

/chatgames skip

Clear the active round. Permission: chatgames.admin (default op).

/chatgames stats [player]

Period and lifetime totals. Permission: chatgames.stats (everyone), chatgames.stats.others (op) for other players. Needs storage.

/chatgames top [game|overall]

Leaderboard menus, players only. Permission: chatgames.top (everyone). Needs storage.

/chatgames toggle

Mute or unmute game messages for yourself. Players only, no permission needed.

/chatgames audit

Prints scheduler branch, versions, per-mode readiness, and storage state. Permission: chatgames.admin (default op).

Config reference

Settings live in four places under plugins/UniversalChatGames/: config.yml (engine, Bedrock, storage, Quizmaster, broadcasts, leaderboard refresh), one file per game in games/ (mechanics and rewards), leaderboard.yml (menu layout, custom icons) and messages.yml (all player-facing text). Edit, save, then run /chatgames reload — no restart needed, and a file with a YAML error keeps the previous settings.

Round timing

global-loop-interval-minutes (15) — how often a round or broadcast fires.

game-timeout-seconds (30) — how long players have to answer.

hide-correct-answer-from-chat (on) — hides the winning message so it can't spoil the next round.

Fairness

loser-feedback-enabled (off) — late correct answers hear "Too slow!", max 2 per round.

disabled-worlds (none) — world names where rounds never start. Good for lobbies and minigame maps.

bedrock-typing-buffer-seconds (3.5) — extra answer time while a Bedrock player is online, so touchscreens stay competitive.

Game modes

The 8 game files — math-flash, word-unscramble, typing-speed, trivia, guess-number, unreverse, fill-in, random-chars — each with enable, display-name, min-players, rewards pool and weight, plus its own settings: value ranges; words, phrases or questions lists; exact-match-case (Typing Speed) or exact-case (Random Characters); min-length, max-length and characters (Random Characters).

Unscramble, Typing Speed, Fill-in and Unreverse can pull words from the built-in library (library: true) minus exclude-words.

trivia.yml questions are question|answer lines with an optional |tier tag (very-easy, easy, basic, medium, hard, very-hard); harder tiers pay more points.

Each rewards entry is type money (min, max) or type command (command, display), with optional weight; see the comments in the game files.

Quizmaster event

Off by default. When on, a named Villager sometimes spawns near a random player asking a high-value question.

chance (0.10) — odds per round. reward-multiplier (3.0) — multiplies money rewards only; command rewards are unchanged. despawn-seconds (60) — how long it sticks around.

Win tracking

storage.enabled turns on the SQLite win log (on for fresh installs). storage.log-reset controls how often the per-period log resets: MONTHLY, WEEKLY, DAYS:30 or NEVER. Turn it off if you don't need records; stats and leaderboards need it on.

Stats and leaderboards

/chatgames stats reads the win log: this period's wins and points per game, plus all-time totals and best times. /chatgames top opens the game list; picking a game (or Overall) opens ranking pages with previous/next navigation and a back button.

leaderboard.yml controls the menu layout (rows, slots, icons, filler). leaderboard.refresh-seconds in config.yml sets how often rankings rebuild (10 to 3600, default 60). Ranking heads show player skins, resolved on a background thread and cached; set custom head icons with game-list.textures.<game> (plus overall).

Sounds

Round events (start, win, lose, timeout, skipped) each play their own sound per game, set in the game file. Anything a game file leaves out falls back to sounds in config.yml; none turns an event off.

Placeholders

With PlaceholderAPI installed: %chatgames_points%, %chatgames_wins%, %chatgames_rank% and %chatgames_best% show the viewer's overall numbers (best is the fastest time), each also per game (for example points_trivia). %chatgames_top_1_name% and %chatgames_top_1_points% show the top row, overall and per game. Past the end of a board, names show placeholders.none (- by default) and points show 0.

Smart broadcasts

Each entry needs an id, a message, and a trigger-type: INTERVAL fires on a timer, TPS fires only when the server lags below tps-below-threshold.

min-players gates quiet servers, cooldown-minutes stops repeats. TPS alerts jump ahead of interval reminders.

Troubleshoot

UnknownDependencyException: Vault on old builds

Update past the softdepend fix; current builds treat Vault as optional.

UnsupportedClassVersionError

The jar targets Java 21 bytecode; run the server on Java 21 or newer.

Missing scheduler: Folia on Folia

Check the enable line; scheduler: Bukkit on Folia means detection failed — report the build.
