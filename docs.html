UNIVERSALCHATGAMES · v1.2

Docs

Install, commands, permissions, and every config key. One page, no hunting.

Install

  1. Drop universal-chatgames.jar into plugins/.
  2. Start the server once to generate config.yml.
  3. Optional: install Vault plus an economy backend. Without Vault, set engine-settings.reward-fallback-command.
  4. Restart. Console must show UniversalChatGames enabled (scheduler: Bukkit) on Spigot/Paper or (scheduler: Folia) on Folia.

Commands

/chatgames reload

Atomic config reload, safe mid-round. Permission: chatgames.reload (default op).

/chatgames start [mode]

Force a round now; rejects when one is active. Modes: MATH, UNSCRAMBLE, TYPING, TRIVIA, GUESS. Permission: chatgames.admin (default op).

/chatgames skip

Clear the active round. Permission: chatgames.admin (default op).

/chatgames toggle

Mute or unmute game messages for yourself. Players only, no permission needed.

/chatgames audit

Prints scheduler branch, versions, per-mode readiness, and storage state. Permission: chatgames.admin (default op).

Config reference

  • engine-settings.global-loop-interval-minutes — minutes between rounds (default 15).
  • engine-settings.game-timeout-seconds — answer window per round (default 30).
  • engine-settings.hide-correct-answer-from-chat — hide the winning message (default true).
  • engine-settings.loser-feedback-enabled — late correct answers get "Too slow!", max 2 per round (default false).
  • engine-settings.disabled-worlds — worlds where rounds never start (default empty).
  • bedrock-settings.bedrock-typing-buffer-seconds — extra answer time when a Bedrock player is online (default 3.5).
  • chat-games.* — per mode: enabled, min-players, reward-amount, weight, announcement-format, plus word/phrase/question lists.
  • chat-games.trivia.questions — one question|answer per line.
  • quizmaster — chance Villager event (default off): enabled, chance, reward-multiplier, despawn-seconds, entity-type.
  • storage.enabled — SQLite lifetime wins + fastest times in wins.db (default false).
  • smart-broadcasts — id, enabled, trigger-type (INTERVAL or TPS), message, min-players, tps-below-threshold, cooldown-minutes.

Troubleshoot

UnknownDependencyException: Vault on old builds

Update past the softdepend fix; current builds treat Vault as optional.

UnsupportedClassVersionError

The jar targets Java 21 bytecode; run the server on Java 21 or newer.

Missing scheduler: Folia on Folia

Check the enable line; scheduler: Bukkit on Folia means detection failed — report the build.
