UNIVERSALCHATGAMES · v1.4

Docs

Install, commands, permissions, and every config key. One page, no hunting.

Install

  1. Drop universal-chatgames.jar into plugins/.
  2. Start the server once to generate config.yml, messages.yml and the games/ folder.
  3. Optional: install Vault plus an economy backend. Without Vault, set engine-settings.reward-fallback-command.
  4. Restart. Console must show UniversalChatGames enabled (scheduler: Bukkit) on Spigot/Paper or (scheduler: Folia) on Folia.

Commands

/chatgames reload

Atomic config reload, safe mid-round. Permission: chatgames.reload (default op).

/chatgames start [mode]

Force a round now; rejects when one is active. Modes: MATH, UNSCRAMBLE, TYPING, TRIVIA, GUESS. Permission: chatgames.admin (default op).

/chatgames skip

Clear the active round. Permission: chatgames.admin (default op).

/chatgames toggle

Mute or unmute game messages for yourself. Players only, no permission needed.

/chatgames audit

Prints scheduler branch, versions, per-mode readiness, and storage state. Permission: chatgames.admin (default op).

Config reference

Settings live in three places: config.yml (engine, Bedrock, storage, Quizmaster, broadcasts), games/ (each game's mechanics and rewards) and messages.yml (all player-facing text). Edit, save, then run /chatgames reload — no restart needed.

Round timing

global-loop-interval-minutes (15) — how often a round or broadcast fires.

game-timeout-seconds (30) — how long players have to answer.

hide-correct-answer-from-chat (on) — hides the winning message so it can't spoil the next round.

Fairness

loser-feedback-enabled (off) — late correct answers hear "Too slow!", max 2 per round.

disabled-worlds (none) — world names where rounds never start. Good for lobbies and minigame maps.

bedrock-typing-buffer-seconds (3.5) — extra answer time while a Bedrock player is online, so touchscreens stay competitive.

Game modes

Each game lives in games/<name>.yml with enabled, display-name, min-players, rewards, weight (pick chance), plus its own word, phrase, or question list. Announcement templates moved to messages.yml under announcements.<game>.

A rewards list holds money entries (min, max, optional weight and display) and command entries (command, display, optional weight); one is rolled per round and %reward% in announcement-format shows it. The old reward-amount still works as one fixed amount.

Trivia lines look like this: What year did Minecraft 1.0 release?|2011|easy — question, pipe, exact answer, and an optional |easy, |medium or |hard tier.

Winner messages

winner.mode picks TITLE, CHAT, BOTH or NONE. New installs show a title.

winner.title and winner.subtitle accept %game% and %reward%; winner.title-times is "fadeIn,stay,fadeOut" in ticks.

Quizmaster event

Off by default. When on, a named Villager sometimes spawns near a random player asking a high-value question.

chance (0.10) — odds per round. reward-multiplier (3.0) — multiplies money rewards only; command rewards are unchanged. despawn-seconds (60) — how long it sticks around.

Win tracking

storage.enabled (off) — saves lifetime wins and fastest times to wins.db for leaderboards. Leave off if you don't need records.

Smart broadcasts

Each entry needs an id, a message, and a trigger-type: INTERVAL fires on a timer, TPS fires only when the server lags below tps-below-threshold.

min-players gates quiet servers, cooldown-minutes stops repeats.

Troubleshoot

UnknownDependencyException: Vault on old builds

Update past the softdepend fix; current builds treat Vault as optional.

UnsupportedClassVersionError

The jar targets Java 21 bytecode; run the server on Java 21 or newer.

Missing scheduler: Folia on Folia

Check the enable line; scheduler: Bukkit on Folia means detection failed — report the build.
