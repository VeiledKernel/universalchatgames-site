Commands

/chatgames reload

Atomic config reload, safe mid-round. Permission: chatgames.reload.

/chatgames start [mode]

Force a round now, any mode or named. Permission: chatgames.admin.

/chatgames skip

Clear the active round. Permission: chatgames.admin.

/chatgames toggle

Mute or unmute game messages for yourself.

Config, not code

Everything lives in config.yml. One example:

chat-games:
  trivia:
    enabled: true
    min-players: 5
    reward-amount: 500.0
    weight: 5
    questions:
      - "What year did Minecraft 1.0 release?|2011"

FAQ

Does it work on Folia?

Yes, native region schedulers with automatic fallback.

Do I need Vault?

No, payouts fall back to console commands you configure.

Will it spam chat?

No. Broadcasts gate on player count, TPS, and cooldowns, and players can mute games.

Do I need a database?

No. Win tracking is optional and off by default.
